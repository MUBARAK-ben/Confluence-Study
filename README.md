# Confluence Study

**Structured study tools for focused progress.**

Confluence Study is a learner and student resource directory designed around practical revision workflows, clear topic breakdowns, and hands-on practice—built with students across Abuja, Kogi, and beyond in mind.

## Key Features
- **Topic Search:** Quickly look up study topics (such as revision, HTML, essays, and exam prep).
- **Session Checklist:** Interactive pre-session readiness checklist to set up focused study or build blocks (picking a clear task, setting a 45-minute distraction-free timer, and summarizing key points in your own words).
- **Structured Guides:** Scannable study guides and workflows to support steady, focused progress.
